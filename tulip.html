Tulip

For This project, we need to select a single object (animal, vegetable, or mineral) that will be included in each of their projects. Within these parameters, we will create many small-scale exploratory projects to learn four different approaches as described in Graphic Design Thinking: Beyond Brainstorming, 1-Icon, Index, Symbol; 2-Action Verbs; 3-Rhetorical Figures of Speech; 4-Forced Connections.
